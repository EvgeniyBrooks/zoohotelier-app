## Подтверждено официальными источниками (10.11.2026)
- Lava заявляет поддержку рекуррентных платежей по банковским картам через API: https://lava.ru/payments/recurring
- Для подключения требуется аккаунт, проект и модерация.
- Lava Business API: https://developer.lava.ru/
- API использует shopId и подпись исходящих запросов HMAC-SHA256 по raw JSON на секретном ключе.
- Входящие webhook проверяются HMAC-SHA256 по raw body на **дополнительном** ключе проекта.
- Приём платежа через POST /business/invoice/create; только подтверждённый webhook или проверка статуса счёта активирует доступ.
- Точные поля и методы **рекуррентной подписки** сверить по актуальной API-документации и возможностям активированного проекта до написания боевого API.

3. Отдельные API: создание подписки с проверкой Telegram initData; webhook Lava с проверкой подписи raw body; получение статуса; отмена автопродления.
