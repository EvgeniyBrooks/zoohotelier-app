## Первая очередь: внедрено в код, необходим пилот в Telegram

1. **Первый вход / карточка собаки.**
   - Для участника без выбранной цели первый вход открывает /journey.html (один раз за сессию); администратору путь не навязывается.
   - Можно выбрать уже заведённую собаку или добавить новую, указать породу/возраст (необязательно), выбрать ровно одну цель, старт «начинаю» или «после курса» и исходное описание.
   - Новые данные привязаны к существующим club_dogs и Telegram student_id, чужую собаку обновить нельзя.
2. **Главная — «Мой следующий шаг».**
   - Из реального состояния выбирается одно действие: карточка → исходное наблюдение → посильная практика / просмотр ответа → сравнение прогресса.
   - Если план доступен, старый блок «Твой маршрут» не дублируется на главной, но остаётся в маршрутах.
3. **Дневник прогресса.**
   - Условия, наблюдение и состояние собаки: спокойно / немного трудно / остановились.
   - Записи сохраняются по собаке в Supabase, сравниваются с исходной точкой; без видео можно вести дневник.
4. **Отчёты по домашнему заданию.**
   - Ссылка из каждого урока на /journey.html?tab=report&lesson=...
   - Текстовый отчёт; опциональное видео MP4/MOV/WebM до 200 МБ и 3 минут напрямую в Cloudflare Stream.
   - Одноразовая ссылка загрузки, приватный video UID, signed playback, ограничение до 3 отчётов в сутки.
   - **По умолчанию приём на проверку закрыт** переменной NOYA_PRACTICE_REVIEW_ENABLED. Включать =1 только после утверждения тарифа сопровождения, команды, бюджета Cloudflare и проверки реальной загрузки на телефоне.
   - Не путать «просмотрел видео», «выполнил практику», «получил проверку» и «продлил подписку».
5. **Кабинет кинолога.**
   - /coach.html — очередь новых/на доработку/проверенных отчётов, просмотр по подписанной ссылке, принятие или один конкретный совет для доработки.
   - Только admins или разрешённые staff в noya_review_staff. Публичный пользователь не видит очередь; прямой URL не выдаёт доступ.
   - Время ответа не обещается, пока не определена реальная пропускная способность команды.

## Критические содержательные исправления P0 — НЕ закрыты программированием

Из аудита 26 уроков:
- Не объяснять агрессию «доминированием» и сном на диване; право на мебель — правило семьи, не диагноз.
- Не объявлять шлейку непригодной для обычных собак: подбирать амуницию по животному и задаче.
- Урок «Салюты и громкие звуки» переснять: не провоцировать страх шарами/шумом, не требовать игнорирования испуга.
- Не оставлять собаку у магазина и не продолжать уход при панике; не заставлять оставаться среди раздражителей до «успокоения».
- Пересмотреть рывки поводком, обязательность кормления с руки и обещания универсальных сроков.
- Согласовать карточку каждого задания с демонстрацией, критериями остановки и облегчением.
- Урок «Рядом» перенести после необходимых предпосылок.
- Удалить из старых видео обещания бессрочного доступа и личной проверки, если они не входят в действующий тариф.

**Не исправлять эти факты одной замаскированной подписью к старому видео.** Нужны обновлённые демонстрации и рецензия кинолога. До этого избегать массовых заданий на опасные фрагменты.

## Поэтапный доступ к курсу «Управление вниманием» (14 ноября)

- Все 26 опубликованных уроков остаются в каталоге; список не скрывается и показываются статусы/время открытия.
- **Предобучение:** оба урока запланированы как доступные сразу, без календарного ожидания. Чтобы воспроизвести второй, нужно просмотреть первый; чтобы перейти к первой неделе, нужно закончить оба.
- **Первая неделя:** её первый урок доступен по дате сразу, но воспроизводится только после завершения предобучения.
- **Начиная с Дня 2:** следующие 23 урока основного курса открываются по одному ежедневно, в **08:00 по Москве**. Время зафиксировано в серверном расписании, чтобы старая переменная Amvera на 10:00 не мешала открытию.
- Личный отсчёт начинается при первом открытии курса, а не при посещении библиотеки или главной клуба. Сохранён в приватной таблице noya_course_drip_starts и не сбрасывается при повторном входе.
- Каждый последующий видеоурок защищён на уровне выдачи данных и Cloudflare Stream token: необходимо закончить все предыдущие; ссылки и библиотека не обходят ограничения.
- «Пройдено» в курсе записывается автоматически после просмотра 90% видео плеером. Ручная кнопка убрана только для курса; домашнее задание и дневник — отдельные события. Для подтверждения используются время просмотра и серверная сессия выдачи токена.
- Администратор может проверять публикацию и порядок без искусственного ожидания. Участники, у которых уже есть отметки, их не теряют.
- Временная зона всех ежедневных открытий — Europe/Moscow (UTC+3). **08:00 МСК — утверждённое время открытия**.

## Вторая очередь — после испытаний первой

- **Тематические маршруты:** база → город → уход → щенок / поездки по потребности. Не публиковать пустые карточки как готовые продукты. Пилотная ветка — кликер либо кафе после готовности реального видео.
- **Эфиры:** один тематический в неделю, вопросы заранее, запись с таймкодами. Архив и просмотр уже существуют — добавить календарь и приём вопросов, когда расписание согласовано.
- **Подписка:** показывать актуальную цену, дату начала и окончания доступа, условия автопродления и отмены, фактический объём помощи. Нельзя подменять существующий Prodamus другим платёжным сценарием.
- **Аналитика:** активация за 72 ч, недельная практика, время ответа на отчёт, продление только по наступившей дате, причины ухода, изменение наблюдений в сопоставимых условиях.
- **Оффер:** курс + посильные действия и поддержка. Большая библиотека — дополнительная ценность, а не главное обещание.
